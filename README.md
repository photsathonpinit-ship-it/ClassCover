# โปรแกรมจัดสอนแทน — ระบบจัดสอนแทนอัตโนมัติ

สำหรับ **ฝ่ายวิชาการ** โรงเรียนไทย ใช้จัดหาครูว่างมาสอนแทนเมื่อครูลา/ไปราชการ

## ฟีเจอร์ครบพร้อมใช้งาน

| เมนู | ทำอะไรได้ |
|------|-----------|
| **แดชบอร์ด** `/` | สถิติ ครูทั้งหมด / ลารออนุมัติ / จัดแล้ว / ยังไม่จัด + แบนเนอร์แจ้งเตือน + ภาระสัปดาห์นี้ (Top 3) + ลาล่าสุด |
| **ปฏิทิน** `/calendar` | มองสัปดาห์ จ-ศ เห็นการลาและคาบจัดแทนแต่ละวัน สลับสัปดาห์ได้ |
| **จัดการครู** `/teachers` | เพิ่ม/แก้ไข/ลบครู ค้นหาชื่อ/วิชา/เบอร์ ปุ่มลัดไปตารางรายคน |
| **ตารางสอน** `/schedule` | ภาพรวม 5 วัน × 8 คาบ สีเขียว=ว่าง เทา=มีสอน คลิกชื่อแก้ตารางรายคน |
| **ตารางรายคน** `/teachers/[id]/schedule` | กรอกวิชา/ห้อง/ชั้น ต่อคาบ |
| **การลา** `/leaves` | ตารางประมวลผล + บันทึกการลาใหม่ (ตรวจวันที่ย้อนหลัง/ลาทับซ้อน) |
| **รายละเอียดลา** `/leaves/[id]` | อนุมัติ/ปฏิเสธ + ระบบแนะนำครูว่างตามวิชาตรง + เลือกจาก dropdown + ยืนยันการจัดแทน |
| **รายการจัดแทน** `/assignments` | กรอง สถานะ/วันที่/ครู + พิมพ์ประกาศ + ส่งออก CSV + เปลี่ยนสถานะเสร็จสิ้น/ลบ |

## วิธีติดตั้งและรัน

```bash
cd teacher-sub
npm install

# สร้างฐานข้อมูล (SQLite ไฟล์ school.db)
npm run db:push

# ใส่ข้อมูลตัวอย่าง 7 ครู + ตารางสอน + 2 ตัวอย่างการลา
npm run db:seed

# รัน dev
npm run dev
# เปิด http://localhost:3000

# ตรวจก่อนส่งมอบ
npm run lint
npm run build
npm start
```

## โครงสร้างข้อมูล

- `teachers` — ชื่อ คำนำหน้า กลุ่มวิชา (JSON) เบอร์โทร คาบสูงสุด/วัน
- `schedules` — ตารางประจำต่อ (teacherId, day MON-FRI, period, subject, room, classLevel)
- `leaveRequests` — ครู ช่วงวัน ประเภท เหตุผล สถานะ pending/approved/rejected
- `subAssignments` — ต่อ 1 คาบ/วัน: ครูที่ลา ครูแทน วิชา ห้อง สถานะ pending/assigned/completed

## กติกาจัดแทนอัตโนมัติ `src/lib/scheduling.ts`

1. หาคาบที่ขาดจาก `schedules` ของครูที่ลาในช่วงวันลา
2. ต่อคาบ หาครูว่าง: ไม่ลาในวันนั้น + ไม่มีคาบสอนตรงกัน + ไม่ถูกจัดแทนคาบนั้นแล้ว + ไม่เกิน `maxPeriodsPerDay`
3. ให้คะแนน: ฐาน 50 + 30 ถ้าวิชาตรงกลุ่มวิชา → เรียงมาก→น้อย เลือกคนแรกเป็น `chosen`
4. บันทึกเมื่อกดยืนยันใน `/leaves/[id]` (เลือกเปลี่ยนคนได้จาก dropdown)

## สคริปต์ที่มี

| คำสั่ง | ทำอะไร |
|--------|--------|
| `npm run dev` | Next.js dev (Turbopack) |
| `npm run build` / `start` | build โปรดักชัน |
| `npm run lint` | eslint |
| `npm run db:generate` / `db:push` | drizzle-kit |
| `npm run db:seed` | ใส่ข้อมูลตัวอย่าง |

## หมายเหตุ

- ฐานข้อมูลเป็นไฟล์ `teacher-sub/school.db` (SQLite via @libsql/client) — สำรองโดยคัดลอกไฟล์
- วันทำการ จ-ศ เท่านั้น เสาร์-อาทิตย์ข้ามในระบบจัดแทน
- ส่งออก CSV มี BOM เพื่อเปิดใน Excel ภาษาไทยไม่เพี้ยน
